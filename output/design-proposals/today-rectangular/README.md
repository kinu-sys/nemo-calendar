# Today — 手描き線と植物の3案

画面の左上・右上・下部のイラストに合わせた、四角寄りの手描き線と小さな植物の透過PNG候補です。
利用者の追加指定に従い、囲み全体をツタにせず、一本の線を基本に植物を対角の一部だけへ減らしています。

| 案 | 画像 | 特徴 |
| --- | --- | --- |
| ① 小花と対角の線枠 | [01-floral-corners.png](01-floral-corners.png) | 左下のピンクの花と右上の小さな蕾 |
| ② 刺繍風の小花と線枠 | [02-embroidered-blossoms.png](02-embroidered-blossoms.png) | 左上の淡い花と右下の小花 |
| ③ 薬草の葉と線枠 | [03-herbal-journal.png](03-herbal-journal.png) | 対角の薬草の葉と控えめな花・蕾 |

[比較画像](comparison.png)・[比較HTML](preview.html)では、現在の装飾と並べた拡大表示、88×44pxの表示目安、月送り画像との組み合わせを確認できます。
比較画像は、枠の内側も透過の初期候補です。文字は縦横中央です。

現在の採用画像は、利用者が添付で指定した「左下のピンクの花と右上のつぼみ」の構図です。[採用画像](../../../public/controls/today-en-floral-paper.png) をアプリに88×44pxで配置しています。参照は添付と同じ 01-floral-corners.png。候補番号より最新の添付指定を優先しています。
枠線を太く、花と葉を少し大きくし、内側に淡いアイボリーの紙を追加。外側は透過、Todayは縦横中央を維持しています。[最新の制作指示](selected-floral-paper-prompt.md)を保存しています。制作は組み込みimagegenの画像編集です。
