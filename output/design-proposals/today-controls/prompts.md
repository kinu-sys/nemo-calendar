## ① 今日

Use case: illustration-story / UI button asset.
Input image: reference for the approved watercolor colors, botanical motifs, ivory surface, muted antique-gold frame and burgundy blossom. It is a STYLE REFERENCE, not a shape requirement.
Create ONE standalone horizontal compact calendar "jump to today" button for Nemo Calendar, matching this reference precisely in natural hand-painted watercolor feel. A small refined European storybook/herbalist journal aesthetic, soft ivory, pale sage wash, fine warm antique-brass/ochre DOUBLE outline, delicate botanical corner scrolls with leaves, ONE small dusty burgundy-red flower with sage leaves near lower left. Elegant mature fairytale stationery. Avoid increasing gold saturation or brightness; no shiny embossed metal, no thick gaudy rim, no 3D render.
Format: landscape button with rounded corners, width:height about 2:1. The button plate should fill almost all the canvas with only a 2–3% transparent margin, as this will be displayed approximately 80px wide by 40px high. Genuinely transparent OUTSIDE the opaque ivory plate.
Center text EXACTLY: "今日". ONLY those two Japanese characters, with correct glyphs, horizontal side by side. Beautiful readable dark olive-brown Japanese Mincho / restrained calligraphic serif lettering, medium-bold enough for small UI use. Make the text prominent but leave room for the botanical frame to remain clearly visible. Fine leaves and flower should hug the borders, curl inward slightly and not overlap the characters. Keep the center's blank space compact rather than excessive. Do not include arrows, English, numerals, labels, mockup background or scenery.
Return a single clean transparent PNG button asset.

## ② Today

Use case: text-localization / precise text-only edit.
Edit target: the attached approved-style watercolor horizontal Japanese "今日" calendar button.
Create its English companion, identical in silhouette, size, proportions, muted colors, watercolor texture, double antique-brass rim, all corner leaf scrolls, single burgundy flower and sage leaves. Preserve the entire plate and decorations. Genuine transparent alpha outside the ivory plate.
Change ONLY the center lettering: remove the Japanese characters and write EXACTLY "Today" (capital T, lowercase oday). Use elegant restrained italic serif / lightly calligraphic lettering, dark muted olive-brown identical to the Japanese lettering. Readable at an 80px-wide by 40px-high UI display. Keep text centered, about 38–42% of overall canvas width, large enough to read but not touching plants. Do not add flourishes that touch or collide with the frame. No other text, no arrows, no extra flowers, no new design elements. Keep same landscape 2:1 aspect ratio, same full-bleed plate with 2–3% transparent margin. No bright gold or 3D effects. Return ONE transparent PNG button.
