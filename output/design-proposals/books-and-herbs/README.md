# 本・瓶・本の上の小物：3つの候補

Nemo Calendar の左上に置く透過PNGの比較提案です。
①の本・乳鉢、②の瓶と中身、③の下部の花を組み合わせた[採用版PNG](../../../public/decorations/books-and-herbs-final.png)を制作し、ヘッダーに反映しました。
採用版の制作指示は [final-prompt.md](final-prompt.md) に保存しています。

| 案 | 画像 | 雰囲気 |
| --- | --- | --- |
| ① 薬草師の乳鉢 | [01-herbal-mortar.png](01-herbal-mortar.png) | 白い乳鉢・薬草・赤い花の瓶。薬草師の手帳らしい、穏やかな案 |
| ② 手紙と赤い花 | [02-letter-and-flower.png](02-letter-and-flower.png) | 葉の封蝋・リボン・花びらの瓶。宮廷の手紙を思わせるロマンチックな案 |
| ③ 小さな砂時計 | [03-hourglass-and-bookmark.png](03-hourglass-and-bookmark.png) | 白と金の砂時計・薬草の栞・青緑の瓶。カレンダーと相性のよい書斎風の案 |

既存画像を本と植物の配置・配色の参考とし、
[ご指定の公式サイト](https://www.clarines-kingdom-fest.com/)の公開キービジュアルを
白と金、赤や青緑の差し色の参考にしています。
制作は組み込み imagegen。実際のプロンプトは [prompts.md](prompts.md) に保存しています。

上記3案は比較用の初稿として保持しています。
採用版では葉先や花が画面端で切れないよう余白を確保し、PC幅・狭幅のヘッダーで表示を確認しました。
