# タスク一覧

このファイルを、このリポジトリのタスク管理場所として使います。ユーザーはチャットでやりたいことを伝えればよく、タスクの追加・状態更新・完了時の整理は作業に合わせてアシスタントが行います。完了したタスクは一覧から外し、利用者に見える変更や重要なデータ変更なら `CHANGELOG.md` に記録します。

## 使い方

- 新しい依頼を受けたら、作業前にタスクとして追加します（すぐ終わる小さな質問・修正は一覧への追加を省略して構いません）。
- 作業中は「作業中」、実装後に確認が残る場合は「確認待ち」とします。
- 対応と必要な確認が終わったらタスクを完了扱いにして一覧から外します。
- 完了内容が利用者に見える変更、またはデータ・権限に関わる重要な変更なら `CHANGELOG.md` に記録します。
- GitHubに同じタスクを重複登録する運用にはしません。

## ステータス

- **未着手**: まだ作業を始めていない
- **作業中**: 対応している
- **確認待ち**: 実装が終わり、動作確認やレビューが残っている

タスクの状態を変えたら、下の一覧も更新します。完了した項目はここに残し続けず、必要な変更履歴に移します。
